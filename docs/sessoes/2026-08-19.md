## HH:MM — Diagnóstico: anexos não chegam no banco VPS

**User pediu:** analisar por que documentos anexados não estão indo pro banco de dados.

**Investigação:**
- Backend `backend-vps/src/routes/uploads.js` OK — grava arquivo em disco e devolve URL.
- Wrapper `frontend/src/services/manutencaoDataSource.js` está com `USE_VPS = true`.
- Auth `pontualApi.js` usa shim `authVPS` via `firebase/config.js` — OK.
- Rotas backend (`manutencoes`, `contratos`, `viagens`) aceitam anexos e gravam PG.

**Bug encontrado:** `frontend/.env.development.local` contém:
```
VITE_PONTUAL_API_URL=http://localhost:3000
```
Esse arquivo tem prioridade máxima no Vite dev. Enquanto ele existir, todo POST/PATCH/upload em modo dev bate em `http://localhost:3000` — nunca chega no Postgres do VPS.

`.env.local` (correto) tem `VITE_PONTUAL_API_URL=` vazio → URL relativa → passa por Apache/VPS → chega em Postgres remoto.
