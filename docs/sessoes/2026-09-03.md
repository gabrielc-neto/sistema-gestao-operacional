# Sessão 2026-09-03

## Reformulação da interface — Layout responsivo global (sidebar + bottom nav)

**Objetivo:** tornar o frontend (React/Vite) responsivo e organizado, unificando a navegação num componente `Layout` persistentes (sidebar desktop + drawer mobile + bottom nav mobile), substituindo os vários `MenuNavegacao` espalhados por página.

**Feito:**

### Novo componente `Layout.jsx` (frontend/src/components/Layout.jsx)
- Sidebar fixa à esquerda (260px) com colapso para ícones (68px) via botão toggle → `is-collapsed`.
- Módulos agrupados (OPERAÇÃO / MONITORAMENTO / ADMINISTRAÇÃO) com filtro de permissão (RBAC `temPermissao` + `canView`), herdando o catálogo do antigo `MenuNavegacao`.
- Header da sidebar: logo "P" + brand + toggle; bloco de usuário; rodapé com tema claro/escuro + Sair.
- **Responsivo:**
  - `≤1024px` sidebar afina em ícones.
  - `≤768px` sidebar vira drawer deslizante (`translateX`), topbar mobile com botão hambúrguer + brand, **bottom nav** fixo (5 atalhos: Home, Frota, OC, Mapa, Manut.), conteúdo `margin-left:0` e `padding-bottom:72px` (espaço p/ bottom nav).
- Overlay com blur ao abrir drawer; fecha no Escape, volta ao roteamento; trava scroll do body.

### `App.jsx`
- Todas as rotas autenticadas agora envolvidas em `Layout` (helpers `LayoutPrivado` / `LayoutPrivada` = `PrivateRoute` + `RotaProtegida` + `Layout`). Rotas públicas (Login, Acesso, Sistemas, Certificado, Intranet, Proposta) ficam SEM layout.

### Remoção do `MenuNavegacao` das páginas
- `MenuNavegacao` retirado de: Dashboard, Frota, Manutencao, Abastecimento, Pneus, FichaPneu, ModuleHeader (componente ficou órfão — só definição, sem import).

### `ModuleHeader.jsx`
- Removido `MenuNavegacao` (agora provido pelo Layout); mantém title/subtitle/actions/back.

### `App.css`
- Substituído boilerplate Vite por estilos do novo layout responsivo (`.app-layout`, `.app-sidebar`, `.app-main`, `.bottom-nav`, `.mobile-topbar`, `.mobile-overlay`, breakpoints 1024/768).

### Responsividade adicional por página
- **Dashboard:** paddings mobile, `.dash-map-wrap` com altura `300px` no mobile, quebra de grades, scroll horizontal em tabelas.
- **Frota:** paddings mobile do header/toolbar, grade de stats `minmax(150px)`.
- **OC:** toolbar empilha verticalmente no mobile, KPIs ficam 2 colunas mesmo em telas estreitas.
- **Manutencao:** sidebar lateral agora vira drawer overlay no mobile (botão hambúrguer no header `manut-sidebar-toggle`, overlay `.manut-sidebar-overlay`, `is-open`), fecha ao trocar de aba; `main`/KPIs zeram `margin-left`.
- **LoginSGO / intranet.css:** já era responsivo (card fluid, overrides ≤480px) — sem mudança necessária.
