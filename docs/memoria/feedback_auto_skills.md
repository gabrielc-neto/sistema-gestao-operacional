Sempre identificar e invocar a skill mais adequada ANTES de responder, sem esperar o usuário chamar `/skill-name`.

**Why:** Usuário pediu explicitamente comportamento proativo — não quer ter que lembrar o nome da skill.

**How to apply:**
- PDF/relatório → ativar `pdf` ou `pdf-reading`
- Excel/tabela → ativar `xlsx`
- PowerPoint/apresentação → ativar `pptx`
- Node.js/script → ativar `nodejs-backend-patterns`
- Planejar tarefa complexa → ativar `planning-and-task-breakdown`
- Agentes/orquestração → ativar `agentic-engineering`
- Contexto/tokens → ativar `context-engineering` ou `token-budget-advisor`
- Análise esportiva → ativar `analise-futebol` + `WebSearch`
