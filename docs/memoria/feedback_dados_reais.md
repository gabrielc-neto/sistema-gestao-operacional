Nunca usar dados fictícios, de exemplo ou placeholder em apresentações, planilhas ou relatórios.

**Why:** O usuário sempre fornece os arquivos reais com os dados e espera que o resultado gerado reflita exatamente esses dados. Dados inventados causam confusão e desconfiança no resultado.

**How to apply:** Antes de gerar qualquer visual (PPTX, XLSX, relatório), ler e processar os arquivos de dados fornecidos. Se nenhum arquivo foi fornecido ainda, perguntar ao usuário quais arquivos usar — nunca inventar valores. Isso vale mesmo quando o pedido menciona "exemplo" ou "preview".
