Sempre usar WebSearch e WebFetch ao fazer qualquer análise esportiva ou pesquisa de jogos.

**Why:** Análises sem dados reais são achismo com vocabulário técnico. Causou picks errados repetidos (Wolves BTTS, Arsenal escanteios, Man City gols individuais).

**How to apply:** Antes de qualquer pick, obrigatoriamente buscar: forma recente, xG, médias de escanteios/cartões, escalação, head-to-head — tudo via web. Nunca inventar ou usar conhecimento de treinamento como dado.
